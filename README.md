### 🔨 Currently Building

**[NextAIToday](https://www.nextaitoday.in) — Founder & Full-Stack Engineer**
AI news & tools discovery platform for the Hinglish-speaking AI audience in India. Started as a static HTML/CSS/JS site, rebuilt into a full-stack app on Next.js + TypeScript + Supabase/PostgreSQL, with a live Groq-powered AI tool finder. 25+ weekly "Sunday Drop" issues published, ranking #1 on Google for "Hinglish AI news."

**Legal AI Backend — AI Engineer Intern @ CourtKachahri**
Building a RAG-based legal AI backend for a legal-tech platform: a multi-persona legal chatbot, retrieval-augmented Q&A over curated Indian legal Acts, and a CNR-based court case-status lookup. Hand-rolled RAG pipeline (no framework) — chunking, asymmetric query/document embeddings via Voyage AI, MongoDB Atlas vector search, and an LLM reranking + query-rewriting step on top of Groq. Containerized with Docker; still pre-production (no auth layer yet, AWS deployment planned next).

**AI Employees — Agentic AI System**
Exploring multi-agent orchestration: one senior/primary orchestrator agent coordinating multiple specialized branch agents. Early-stage, actively designing the architecture.
