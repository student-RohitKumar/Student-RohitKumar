### ⚖️ Legal AI Backend — AI Engineer @ CourtKachahri

Building a RAG-based legal AI backend for a legal-tech platform.

Core work includes:

- Multi-persona legal AI assistant
- Retrieval-augmented Q&A over curated Indian legal Acts
- Document-based Q&A
- CNR-based court case-status lookup
- Custom RAG pipeline built without LangChain or LlamaIndex
- Document/query embeddings using Voyage AI
- MongoDB Atlas Vector Search
- LLM-based reranking
- Conversational query rewriting
- Context-grounded response generation
- Dockerized backend

The system is still evolving toward production, with several infrastructure and security improvements planned.
